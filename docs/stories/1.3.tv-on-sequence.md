# Story
**As a** user,
**I want** a "CRT TV turn-on" animation to transition from the boot screen to the main portfolio,
**so that** the experience feels cohesive and impressive.

# Acceptance Criteria
1.  Upon completion of the boot sequence, a transition effect mimicking a CRT monitor powering on is displayed.
2.  The effect smoothly hides the boot screen and reveals the main portfolio view.
3.  The transition is brief (1-2 seconds) and visually engaging.

# Tasks / Subtasks
-   [x] **Task 1: Create CSS Animations (AC: 1, 3)**
    -   [x] In `style.css`, create a CSS keyframe animation named `tv-turn-on` that uses `transform: scaleY()` to expand a pseudo-element vertically, as described in the architecture.
    -   [x] Create a secondary, short keyframe animation for a subtle "glitch" effect to be applied during the transition, per the UI/UX spec.
    -   [x] Apply these animations to a class (e.g., `.transitioning`) that can be added to the `#boot-screen` or a dedicated overlay element.
-   [x] **Task 2: Implement Transition Logic (AC: 1, 2)**
    -   [x] In `script.js`, implement the `transitionToMainView` method within the `AppController` module.
    -   [x] This method should be called once the `Promise` returned by the `BootSequence.run()` method (from Story 1.2) resolves.
    -   [x] When called, `transitionToMainView` will add the CSS class created in Task 1 to trigger the animation.
-   [x] **Task 3: Finalize State Change (AC: 2)**
    -   [x] Add an `animationend` event listener within `transitionToMainView`.
    -   [x] Once the CSS animation completes, the event listener should fire and execute the final DOM manipulation:
        -   Set `display: none;` on the `#boot-screen` element.
        -   Set `display: block;` (or similar) on the `#main-portfolio` element.

# Dev Notes
-   **Dependency**: This story is dependent on the completion of Story 1.2. The transition logic must be triggered by the successful completion of the boot sequence (i.e., after the `BootSequence.run()` promise resolves).
-   **Animation Specification (from UI/UX Spec)**: The animation must follow this sequence:
    1.  A single, bright horizontal line appears in the vertical center.
    2.  A split-second "glitch" flickers over the line.
    3.  The line rapidly expands vertically to fill the screen, revealing the portfolio.
-   **Technical Implementation (from Architecture)**:
    -   The effect should be primarily achieved with CSS keyframe animations, not JavaScript animation loops.
    -   The recommended technique is to use a pseudo-element (e.g., `#boot-screen::before`) and animate its `transform: scaleY()` property.
    -   The orchestration logic belongs in `AppController.transitionToMainView()`.
