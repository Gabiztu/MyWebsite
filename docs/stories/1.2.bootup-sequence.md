# Story
**As a** user,
**I want** to see an immersive boot-up sequence when I first load the page,
**so that** I am immediately drawn into a unique, high-tech experience.

# Acceptance Criteria
1.  On page load, the boot sequence from `porto4.html` is displayed, matching its visual appearance and text content exactly.
2.  The text typing animation is noticeably faster than the original example in `porto4.html`.
3.  The main portfolio content is not visible during the boot sequence.

# Tasks / Subtasks
-   [ ] **Task 1: Implement Boot Screen HTML & CSS (AC: 1, 3)**
    -   [ ] Copy the `#boot-screen` div and its content from `porto4.html` into the `<body>` of `index.html`.
    -   [ ] Copy all necessary CSS for `#boot-screen` and its child elements from `porto4.html` into `style.css` to ensure an identical visual match.
    -   [ ] Verify that the `#main-portfolio` container in `index.html` remains hidden by default (`display: none;`).
-   [ ] **Task 2: Implement Boot Sequence Logic (AC: 1, 2)**
    -   [ ] Implement the `BootSequence` module in `script.js` as defined in the architecture document.
    -   [ ] Port the `bootLog` array (the text to be typed) from `porto4.html` into the `BootSequence` module.
    -   [ ] Port the `typeLine` and `run` (formerly `runBootSequence`) logic from `porto4.html` into the `BootSequence` module's methods.
    -   [ ] In the `typeLine` function, adjust the typing interval from the original `20ms` to `15ms` to meet the "noticeably faster" requirement.
-   [ ] **Task 3: Integrate with App Controller (AC: 1, 3)**
    -   [ ] In the `AppController` module in `script.js`, call the `BootSequence.run()` method when the application initializes.
    -   [ ] Ensure the `BootSequence.run()` method returns a Promise that resolves when the animation is complete. This will be used to trigger the transition in the next story (1.3).

# Dev Notes
-   **User Requirement**: The user has specified that while the typing speed should be slightly faster, the visual appearance, text content, and overall feel of the boot sequence must **exactly match** the implementation in the reference file `porto4.html`.
-   **Source of Truth**: All HTML, CSS, and JS logic for the boot sequence must be ported directly from `porto4.html`.
-   **Architectural Placement**: This logic must be encapsulated within the `BootSequence` module as defined in `docs/architecture.md#bootsequence-module`.
-   **Integration**: The `AppController` is responsible for initiating the sequence. The sequence must signal its completion so that the transition in Story 1.3 can be triggered.

# Testing
-   **Manual Validation**:
    1.  Load `index.html` in a browser.
