# Dev Notes
-   **Architectural Module**: The JavaScript logic for the tilt effect belongs in the `Portfolio` module in `script.js`. The CSS enhancements should be applied to the `.card` and `.shine` selectors in `style.css`.
-   **UI/UX Specification**:
    -   **Hover Effect**: "The card's border color will brighten, the `box-shadow` will deepen for a sense of depth, and the 'shine' effect will be more pronounced. The card will tilt slightly towards the cursor."
-   **Click Effect**: While the full modal interaction is handled in Story 1.7, this story should implement the immediate visual feedback *of the click itself* via a CSS `:active` state.
-   **Performance**: The tilt effect should be performant. Using a CSS `transform` is hardware-accelerated and is the correct approach. Ensure the event listeners are efficient.

# Testing
