# Story
**As a** developer,
**I want** to enhance the Matrix background effect,
**so that** it looks more sophisticated and unique.

# Acceptance Criteria
1.  The character set used in the background animation is replaced with non-alphanumeric, esoteric Unicode symbols (e.g., Katakana, box-drawing characters) as specified in the UI/UX document.
2.  The animation includes subtle variations in the falling speed of different columns and an intermittent "flicker" effect on some characters.
3.  The animation is highly performant, driven by `requestAnimationFrame`, and does not cause significant browser slowdown.
4.  The background effect correctly updates its colors when the theme is changed via the `ThemeSwitcher` module.

# Dev Notes
-   **Architectural Module**: All logic for this story should be implemented within the `MatrixBackground` module defined in `docs/architecture.md`.
-   **Aesthetic Guidance (from UI/UX Spec)**:
    -   **Characters**: Use "esoteric Unicode characters (e.g., Katakana, box-drawing symbols, block elements)."
    -   **Animation**: The goal is "subtle variations in the falling speed" and a "flicker effect on some characters." The feel should be sophisticated, not chaotic.
-   **Performance**: NFR4 requires all animations to be smooth and performant. Use of `requestAnimationFrame` is mandatory. Avoid any logic that could cause layout thrashing or excessive repaints.
-   **Integration**: This module must integrate with the `ThemeSwitcher` module. The architecture specifies that `ThemeSwitcher` will call `MatrixBackground.updateTheme()`. While `ThemeSwitcher` is built in a later story, the `updateTheme` method should be implemented now to read the live CSS variable, making it ready for future integration.
