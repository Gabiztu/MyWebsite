# Story
**As a** user,
**I want** to click on a project and see a dynamic modal with an animated preview,
**so that** I can quickly and impressively grasp the nature of the work.

# Acceptance Criteria
1.  Clicking a project card triggers a loading bar animation.
2.  When the loading bar finishes, a modal window opens with an engaging animation.
3.  Inside the modal, an animated GIF preview of the project is displayed.
4.  The modal contains a clearly visible button/link to "View Live Project".
5.  Closing the modal is smooth and returns the user to the project grid.

# Dev Notes
-   **User Requirement Update**: The project preview will be an **animated GIF**, not a video. The creation of the final GIF assets is **out of scope** for this story. The implementation must use a placeholder GIF located in the `/assets/` directory.
-   **Architectural Module**: All JavaScript logic belongs in the `Portfolio` module.
-   **Animation & Flow Specification (from UI/UX Spec)**:
    -   **Loading Bar**: "Fills smoothly... triggers 'data corruption' glitch effect before disappearing."
    -   **Modal Opening**: "Animate in using a combination of `scale` (from 0.95 to 1) and `opacity` (from 0 to 1)... subtle pixelation effect that quickly resolves."
    -   **Modal Closing**: "Smoothly fade and scale down without any glitch effect."
-   **Asset Convention**: A naming convention like `project-[projectId].gif` should be used, where `[projectId]` matches the `data-project` attribute on the card (e.g., "hyperviz", "fintech-core").
